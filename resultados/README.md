# Resultados locales

Esta carpeta contiene exportaciones y salidas de ejecución. Los experimentos
conservan su identificación en la base de datos; las exportaciones reúnen
predicciones, métricas, exclusiones, configuraciones y un manifiesto de huellas.
Los resultados generados están excluidos de Git.

Ver [evaluación](../docs/EVALUACION.md) para ejecutar y exportar un experimento.
